Free, open-source custom mouse cursors, cursor effects and a cursor designer. 235 original skins, Mouse X skin import, trails and click effects, per-app profiles and global hotkeys.

## Download

| System | File | How to run |
|---|---|---|
| **Windows 10/11** | `MouZe-windows.zip` | Unzip anywhere and run `MouZe\MouZe.exe`. If SmartScreen warns about an unrecognised app, choose **More info → Run anyway** (the build isn't code-signed). |
| **Linux** (x86-64) | `MouZe-linux.tar.gz` | `tar xzf MouZe-linux.tar.gz && ./MouZe/MouZe`. You may need `libegl1 libxkbcommon0` installed. |
| **macOS** | `MouZe-macos.zip` | Unzip and move `MouZe.app` to Applications. The app is unsigned, so right-click it and choose **Open** the first time. macOS doesn't let apps change the system cursor, but effects, Studio and every export work. |

Prefer Python? `pip install git+https://github.com/AlphaMeep/MouZe-.git`, then run `mouze`.

## Getting started

1. Open **Library**, pick a skin and try it in the test area.
2. Click **Apply**. Your cursor changes system-wide and stays changed after you close MouZe.
3. To go back, use **Settings → Restore my previous cursors** or press <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd>.

Coming from Mouse X? **Library → Import → From Mouse X / Steam Workshop…** converts the skins you already downloaded.

See the [README](https://github.com/AlphaMeep/MouZe-#readme) for everything MouZe can do.
